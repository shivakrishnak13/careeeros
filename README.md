# CareerOS 🚀

An AI-powered career management platform that helps users track job applications, manage interviews, prepare with AI tools, and analyze their job search progress — all in one modern workspace.

🌐 Live Demo: https://careeeros.vercel.app/

---

## ✨ Features

### 🔐 Authentication & Security
- Secure JWT-based authentication
- Protected dashboard routes
- Login & registration system
- Secure cookie handling

---

## 📋 Application Tracking
Track and manage all job applications from a centralized dashboard.

### Features
- Create, edit, and delete applications
- Track application statuses
- Add recruiter/company details
- Save salary expectations
- Search and filter applications
- Responsive data tables and forms

### Application Statuses
- Applied
- Interview
- Offer
- Rejected
- Wishlist
- Withdrawn

---

## 🎤 Interview Management
Organize and manage interview rounds efficiently.

### Features
- Schedule interview rounds
- Track interview progress
- Add interview notes & feedback
- Manage multiple rounds per application
- Upcoming interview tracking

---
